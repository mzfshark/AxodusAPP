# Component specifications

## Hero

Required order: institutional badge → H1 → concise supporting text → primary action → optional secondary action → decorative SVG. One H1 per page. Copy sits within 8/12 columns; visual is absolute and never carries information necessary to understand the page.

## Section

Use `.ax-section` and `.ax-container`. Header follows eyebrow → H2 → description. Default vertical gap is 128px desktop and 64px mobile. Do not place a card grid immediately after a hero without a section boundary.

## Cards

Use for peers, not paragraphs. Keep title to two lines and supporting copy to three lines. Three-column grid on desktop; one column mobile. Never invent card colors; interactive state uses the shared hover state.

## CTA

Exactly one primary treatment within a visual region. Secondary CTAs are outline/surface. Button labels begin with a verb and stay under 28 characters.

## Badges

Badges name a category, state, sequence, or institutional proof point. No marketing sentences. Keep to 2–4 words.

## Navigation and footer

Navigation stays single-line on desktop and may collapse to a menu under 900px. Footer uses subdued text and a top divider; it must never compete with a page CTA.

## Timeline and architecture

Timeline is chronological only. Architecture blocks represent flows or system layers: 3 or 6 nodes maximum per visible group, mono labels, no decorative arrows unless showing a real relationship.
