# Axodus Institutional UI Pack

The durable visual contract for every Axodus institutional page. Start with the tokens, compose only documented components, and use the SVG library for hero balance without adding arbitrary decoration.

## Quick start

1. Load `02-foundations/tokens.css` before page styles.
2. Apply `03-components/components.css`.
3. Copy a pattern from `03-components/examples.html`.
4. Follow `06-guides/UI-RULES-FOR-CODEX.md` for every change.

## Contents

- `01-brand` — palette and typography specification
- `02-foundations` — design tokens and layout primitives
- `03-components` — component CSS and implementation examples
- `04-assets/svg` — transparent hero and blueprint illustrations
- `05-specs` — component contracts
- `06-guides` — operating rules for Codex agents

All assets are local, dependency-free, and licensed for Axodus project use.
